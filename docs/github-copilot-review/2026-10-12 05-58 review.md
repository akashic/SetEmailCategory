## Findings

### [P1] Validate the full Exchange management-scope filter

`scripts/Grant-MailboxAccess.ps1:94-95`

For an existing management scope, the script only checks whether its filter contains the mailbox address. A broader or inverted filter such as `PrimarySmtpAddress -ne 'target@contoso.com'` passes that check; the script can then proceed to assign `Mail.ReadWrite` against a scope that includes other mailboxes. Compare the existing filter against the intended single-mailbox filter semantically before using it, and validate any pre-existing role assignment's role, service principal, and scope. No tests currently cover these checks.

### [P2] Configure the correct OAuth token endpoint

`connector/apiDefinition.swagger.json:103-105`

The Swagger 2.0 `accessCode` security definition uses an authorization endpoint for `tokenUrl`. OAuth clients exchange authorization codes at the token endpoint, so a client following this definition will send the exchange to the wrong endpoint and fail authentication. Set the correct Microsoft identity token endpoint and keep it consistent with the custom connector OAuth settings.
