  - **Network:** after each diagram it checks a GitHub Pages URL for a newer version. It only reports one, and `ARCHIFY_UPDATE_CHECK_DISABLED=1` turns the check off.

  - **Location:** the files sit next to the anatomy figures, not in `.archify/`, as the user asked. Archify's `.delivery.json` receipts are kept, because it needs them to recheck the pages later.

Main had moved, because PR #15 had merged the first diagrams commit, so the new commit was cherry-picked onto `origin/main`. The user ran the commands to do that and push. The `docs-architecture-diagrams` branch was then deleted locally. It had already been removed from GitHub when PR #15 merged.
