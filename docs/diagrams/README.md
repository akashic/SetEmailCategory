# Diagrams

Two interactive figures. Each is a standalone HTML page in a dark and a light version. Open either page in a browser. Hover a part or a numbered button, or use the arrow keys, to see what each station is. When idle, each figure walks through its stations in order.

| Figure | Pages | Shows |
|---|---|---|
| Setting a category | [`solution/solution.html`](solution/solution.html), [`solution/solution-light.html`](solution/solution-light.html) | <ul><li>The Azure resources, from the Power Automate call through App Service Authentication to the function app.</li><li>Its managed identity, Graph and Exchange RBAC reaching the one shared mailbox.</li><li>VNet integration through the platform's shared VNet, and storage behind private endpoints with private DNS.</li><li>Monitoring and alerts.</li></ul> |
| Deploying from GitHub | [`deployment/deployment.html`](deployment/deployment.html), [`deployment/deployment-light.html`](deployment/deployment-light.html) | <ul><li>The manual workflow run, the build, and the prod environment gate.</li><li>The OIDC token exchanged for the deployment identity.</li><li>The identity's roles: Contributor, a constrained RBAC Administrator grant, and network grants on the platform VNet.</li><li>The deploy steps: pre-flight checks, infrastructure, code and the smoke test.</li></ul> |

The facts in the readouts and captions come from `infra/`, `scripts/` and `.github/workflows/deploy.yml`. If those change, update the station tables in each `build.mjs` and rebuild.

## Rebuilding

The pages are generated by `build.mjs` in each folder, using the [anatomy](https://skills.sh/wheresryan22/anatomy) skill's drawing kit. `kit.mjs` loads the kit from `~/.agents/skills/anatomy`, or from `ANATOMY_SKILL` if that's set. You need Node.js 20.10 or later.

```bash
npx skills add wheresryan22/anatomy -g   # once

node docs/diagrams/solution/build.mjs && node docs/diagrams/solution/build.mjs --light
node docs/diagrams/deployment/build.mjs && node docs/diagrams/deployment/build.mjs --light
```

Before committing a change, run the geometry audit and the line-end check. The line-end check needs Chrome or Chromium.

```bash
node docs/diagrams/solution/build.mjs --audit
node ~/.agents/skills/anatomy/scripts/lines.mjs docs/diagrams/solution/solution.html
```
